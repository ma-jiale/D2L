2.1.8. 练习
Run the code in this section. Change the conditional statement X == Y to X < Y or X > Y, and then see what kind of tensor you can get.
在这一部分运行代码。将条件语句 X == Y 更改为 X < Y 或 X > Y，然后看看你能得到什么样的张量。

更改为 X < Y 之后得到的张量与 X、Y 形状相同，但是会比较 X 和 Y 在同一个位置的元素：当 X 这个位置的元素小于 Y 这个位置的元素时，这个新张量的这个位置元素为 True，反之为 False。
更改为 X > Y 之后得到的张量与 X、Y 形状相同，但是会比较 X 和 Y 在同一个位置的元素：当 X 这个位置的元素大于 Y 这个位置的元素时，这个新张量的这个位置元素为 True，反之为 False。

Replace the two tensors that operate by element in the broadcasting mechanism with other shapes, e.g., 3-dimensional tensors. Is the result the same as expected?
用其他形状的张量，例如三维张量，替换在广播机制中逐元素操作的两个张量。结果是否与预期相同？

1）当广播操作中两个同维度张量时，
广播机制按照以下两步程序进行工作：
（i）通过沿着长度为1的轴复制元素来扩展一个或两个数组，以便在此转换后，这两个张量具有相同的形状；
（ii）对结果数组执行逐元素操作。
3）当广播操作中两个不同维度张量时，例如一个二维张量和一个三维张量，会将二维张量转化为第三个轴长度为1的三维张量然后参照同维度张量的操作进行
但是注意：PyTorch 在进行二元运算时，会从最右侧（末尾）维度开始向左逐一对齐并检查兼容性。两个维度兼容（能够广播处理）的条件是：
相等，或
其中一个为 1，或
其中一个不存在（缺失的维度视为 1）
